# 2026.292.2019 — feat(skills): move the four `hermes` skill bodies to .agents/skills

## Summary

Moves the four `hermes` skill bodies out of the manifest and into the repo that owns them: `.agents/skills/<name>/SKILL.md`. Each `skill:` node keeps its routing metadata — `name`, `family`, `owner`, `description` — and no longer carries a body of its own.

The generator already reads this shape. `plugin-marketplace/candy/plugin-marketplace/skillfile.go` takes the body from the first declared tree that holds the file, defaults the id to the node name, and hard-errors when a node's inline `content:` disagrees with the file (*"delete the inline body and keep the file"*). So the dedupe rule R5 asks for is enforced mechanically, not by convention.

**Why the proof below is the generator and not `charly box validate`:** `box validate` passes here but it counts no skills (`1 candy, 7 distros, 7 builders`), and — measured — it still returns `rc=0` with a relocated `SKILL.md` deleted outright. It cannot see this change. The gate with teeth is the generator's own reader run against this tree, and the two tests below are red/green on exactly the thing that could go wrong.
